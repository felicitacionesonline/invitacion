# 👑 Invitación Digital de XV Años - Mayra Nicol

Bienvenidos al proyecto de la invitación digital para celebrar los XV años de **Mayra Nicol**, diseñada con un estilo elegante, romántico y mágico.

La página está inspirada en una temática de princesa, con tonos verde esmeralda, verde menta y dorado, acompañados de mariposas, flores y detalles decorativos.

## ✨ Características

- 👑 Diseño elegante y temático de XV años.
- 🦋 Animaciones de mariposas y destellos.
- 💚 Colores verde esmeralda, verde menta y dorado.
- ⏳ Cuenta regresiva para el día del evento.
- 📍 Enlace directo a Google Maps para consultar la ubicación.
- 💬 Botón de WhatsApp para confirmar asistencia.
- 📱 Diseño adaptable a celulares, tablets y computadoras.
- 🎶 Opción de música de fondo, si está configurada.

## 📅 Datos del evento

- **Quinceañera:** Mayra Nicol.
- **Fecha:** Sábado 24 de octubre de 2026.

## 🚀 Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta el archivo `index.html` en tu navegador.
4. Disfruta de la invitación digital.

No es necesario instalar dependencias para la versión estática, siempre que el proyecto no utilice herramientas adicionales.
